## Contents (approximate)

- Checkerboard ground plane
- **Stair-like box stacks** near `y ≈ 4` and `y ≈ 6` (ascending along +x from ~1.2 m)
  - Coarse tread ~0.2 m (x), half-width ~0.75 m; riser heights vary by row
- Dense **random box cluster** around `x ∈ [-2.3, -0.6]`, `y ∈ [5.1, 6.7]` (scattered rubble)
- One **heightfield** geom (`perlin_hfield`): size half-extents `1.0 × 0.75 m`, elevation scale `0.2 m`, base `0.2 m`, centered near `(-1.5, 4.0, 0)`

> Note: stair / rubble boxes are baked as absolute geoms in `scene.xml` (legacy export); they are not regenerated by `generate_stairs_terrain.py`.
