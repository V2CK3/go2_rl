# LCM Types（部署链路 Step 1）

本目录定义 Python 策略与 C++ `bridge/lcm_position_go2` 之间的消息格式。

## 哪些是手写的？哪些是自动生成的？

| 文件 | 来源 | 是否可改 |
|------|------|----------|
| `*.lcm` | **手写**消息定义 | 可以改 |
| `*.py`、`*.hpp` | 由 `lcm-gen` **自动生成** | **不要手改** |

生成文件头部都有类似标记：

```text
This file automatically generated by lcm.
DO NOT MODIFY BY HAND!!!!
```

## 如何重新生成

修改某个 `.lcm` 后，在本目录执行：

```bash
# 生成 C++ 头文件
lcm-gen -x xxx.lcm

# 生成 Python 绑定
lcm-gen -p xxx.lcm
```

示例：

```bash
cd sim2real_deploy/lcm_types
lcm-gen -x pd_tau_targets_lcmt.lcm
lcm-gen -p pd_tau_targets_lcmt.lcm
```

## 本项目使用的核心消息

- `leg_control_data_lcmt`：关节位置/速度/估计力矩（C++ → Python）
- `state_estimator_lcmt`：姿态、角速度、足力等（C++ → Python）
- `rc_command_lcmt`：遥控器摇杆与按键（C++ → Python）
- `pd_tau_targets_lcmt`：期望关节角与 PD 增益（Python → C++）
